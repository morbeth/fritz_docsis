# FRITZ!Box DOCSIS Monitor

Home Assistant Custom Integration für DOCSIS Monitoring von AVM FRITZ!Box Cable Geräten.

## Features

- DOCSIS 3.0 + 3.1 Werte
- MER/MSE
- Power Level
- Fehlerüberwachung
- Signalbewertung
- Home Assistant Dashboard
- Push-Warnungen

## Installation

### HACS

HACS → Benutzerdefinierte Repositorys

Repository hinzufügen:

https://github.com/DEINNAME/fritz_docsis

Kategorie:

Integration

Dann:

HACS → Integrationen → FRITZ!Box DOCSIS Monitor

installieren.

## Unterstützte Geräte

- FRITZ!Box 6591
- FRITZ!Box 6660
- FRITZ!Box 6690

## Hinweis

AVM stellt keine offizielle DOCSIS API bereit.
Die Integration liest die Weboberfläche der FRITZ!Box aus.
